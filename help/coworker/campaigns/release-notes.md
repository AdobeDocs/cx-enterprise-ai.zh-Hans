# Adobe CX Enterprise Co-worker Campaign发行说明 {#release-notes}

协作营销活动版本在持续交付模型上运行，通过该模型可采用更具可扩展性、分阶段的方法部署功能。

## 2026 年 7 月 {#july-2026}

**发行日期： 2026年7月23日**

* 安排营销活动以立即发送、在选定的时间发送一次或定期发送
* 管理联系人列表中的取消订阅列表，并在Campaign电子邮件设置中设置取消订阅参数
* 使用新的表单清单和编辑器构建和管理表单
* 当凭据失败时（包括更新现有连接时），连接器设置显示更清晰的指导
* Marketo连接现在支持Experience Cloud URL
* 域和发件人向导在域上线之前捕获到更多DNS记录问题
* 直接从营销活动输入的“添加”菜单添加连接器
* 库存页面在尚未显示任何内容时显示更友好的以空状态图示
* 营销活动见解显示哪些数据源支持每个量度
* 现在，品牌编辑器已内置到载入中，以实现更顺畅的首次设置
* 在提交到营销活动之前预览示例受众
* 同事营销活动现在位于统一的Experience Cloud导航外壳程序中
* 已移除用于清洁器活动板的浮动反馈提示栏
* 整个过程中的各种性能和可靠性改进

**发行日期： 2026年7月14日**

* 域和发件人转出、实时工作流进度和真正的活动分析
* 域和发件人设置现已完全可用，发件人选择会自动保存
* 从Campaign设置中选择或更新活动电子邮件发件人
* 即使在验证域之前，“发件人”选项卡仍可浏览
* 在对话过程中添加的电子邮件草稿现在可靠地显示在活动展示板上
* 帮助和反馈合并为一个简化的弹出框
* 开始新对话时不再显示最后一个对话的剩余消息
* 多圈对话不再在响应抽屉中显示过时的提示
* 聊天消息中的编号列表按正确顺序排列
* HubSpot连接器安装程序现在会要求提供与HubSpot自己的术语相匹配的服务密钥
* 试用管理表显示用户计数，不再剪辑最后一行
* 整个过程中的各种性能和可靠性改进

**发行日期： 2026年7月9日**

* 现在，维护横幅和对话框会在计划停机之前警告您
* 域和发件人具有引导式设置向导，用于验证域和添加发件人
* 现在，草稿营销活动会提示您先完成电子邮件和渠道设置，然后再发送
* 域和发件人验证捕获到更多问题，包括DNS记录边缘案例
* 用户档案菜单已移至侧栏，以便更快速地访问
* Source PDF文档现在显示为brand kit详细信息中的“丸子”
* 整个过程中的各种性能和可靠性改进

**发行日期： 2026年6月26日**

* 新的分析仪表板可显示促销活动效果KPI：发送、打开、点击、退回等
* 营销活动在展示板上显示实时状态徽章，以便您一眼就能看到活动发送
* Campaign展示板中会显示上下文提示，以指导您完成后续步骤
* 新用户入门使用您的真实品牌数据使设置体验个性化
* 品牌拾色器可处理速记十六进制代码并在简洁弹出框中打开
* 现在可以从应用程序设置配置UTM参数和消息上限
* 帮助链接现在可直接在Experience League上打开最新内容
* 整个过程中的各种性能和可靠性改进

**发行日期： 2026年6月24日**

* 现在发起一场营销活动会引发一场五彩纸屑庆典
* 营销活动显示状态徽章，展示板在启动后锁定为只读
* 品牌概述适合您的屏幕，具有空状态提示和更好的徽标显示
* 即使返回了意外的错误类型，验证仍会显示一个清晰的对话框
* 生成的电子邮件内容使用您的营销活动目标获得更相关的结果
