# 计划活动 {#schedule-campaign}

在启动营销活动时，用户现在可以选择确切的退出时间：立即、在特定的未来日期和时间，或按重复（定期）计划。 用户也可以稍后返回，更改已启动或计划的营销活动的计划。

> **更改了哪些内容**：以前，只能立即启动营销活动。 此版本添加了一次性未来计划、定期计划和启动后编辑计划的功能。

## 先决条件

- 活动必须准备好启动（完成所有必需的设置）。
- 除活动处于可启动状态外，不需要任何其他先决条件。

## 此功能的功能

当用户启动营销活动时，他们会选择三种计划模式之一，然后进行确认。 所选计划可确定营销活动何时开始发送，对于定期营销活动，还可确定其重复频率以及何时结束（或是否结束）。 在活动被安排或处于实时状态后，可以从活动设置中编辑其计划。

### 关键行为

- 启动时可以使用三种计划模式：**现在**、**计划一次**&#x200B;和&#x200B;**定期**。
- 为将来计划的营销活动在开始时间到来之前显示“已计划”状态，然后自动切换到“实时”。
- 已开始的定期营销活动显示“实时”及其定期摘要（例如，“每周星期二上午9:00点钟”）。
- 循环营销活动可以设置为无限期运行（“从不”结束）或直至特定结束日期。 一次性营销活动和即时营销活动没有结束日期选项，因为它们只运行一次。
- 用户可以使用相同的计划选项，从营销策划的设置中编辑已启动或计划的营销策划的计划。

## 使用方法

**要在启动时计划促销活动，请执行以下操作：**

1. 在营销活动中，单击&#x200B;**准备启动**。
2. 在启动对话框中，选择一个计划选项：
   - **现在** — 营销活动在启动后立即开始发送。
   - **计划一次** — 选择未来的&#x200B;**开始日期**（日期和时间）。
   - **周期性** — 选择&#x200B;**频率**（每日、每周或每月）和开始时间，然后设置周期模式（请参阅下面的字段）。
3. 如果选择了“定期”，请选择营销活动是&#x200B;**从不**&#x200B;结束，还是&#x200B;**在日期**&#x200B;结束，并选择结束日期（如果适用）。
4. 确认使用选定的计划启动营销活动。

**要编辑现有计划：**

1. 打开营销活动，然后转到其设置。
2. 查找调度部分，然后选择当前调度摘要。
3. 使用上述相同选项更新计划。
4. 保存更改。

### 输入字段/参数

| 字段 | 描述 | 必需？ |
| --- | --- | --- |
| 计划模式 | 选择“现在”、“计划一次”或“周期性” | 是 |
| 开始日期 | 活动开始的日期和时间（计划一次模式） | 是，计划一次 |
| 频率 | 每日、每周或每月（循环模式） | 是，对于周期性 |
| 开始时间 | 定期营销活动发送的时间 | 是，对于周期性 |
| 每周天数 | 活动在哪一天重复 | 是，针对每周频率 |
| 每月的第几日 | 活动在一个月中的哪一天重复 | 是，用于月频率 |
| 结束营销活动 | 从不，或者在特定的结束日期 | 是，对于周期性 |

## 此功能不具备的功能

- 它不支持自定义重复间隔，例如“每2周”或“每3天” — 只有标准的“每日”、“每周”或“每月”频率可用。
- 它不支持相对每月重复，例如“每月的第二个星期一” — 只有特定的每月日期选择可供每月选择。
- 它不提供&#x200B;**现在**&#x200B;或&#x200B;**计划一次**&#x200B;营销活动的结束日期 — 仅在选择“循环”时提供结束日期，因为一次性营销活动按定义运行一次。
