# 如何从自然语言提示生成历程

传统上，构建客户历程需要跨触发器、时间规则、渠道、决策逻辑和消息传送步骤进行广泛配置。 在此视频中，您将了解Co-worker如何通过将纯语言描述转换为Adobe Journey Optimizer中完全草稿的历程来简化该过程。
 
通过自动化初始设置过程，团队可以花更少的时间从头开始构建历程，花更多时间优化客户体验和业务成果。
